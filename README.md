# Трекер прочитанных книг

Консольное приложение на Python для учёта прочитанных книг.

## Возможности

- Добавление книги (автор, название, оценка 1–5, дата прочтения).
- Просмотр всех книг.
- Средняя оценка по всем книгам.
- Статистика по авторам.
- Удаление книги.

## Как запустить

```bash
python main.py
```

## Формат данных

Книги хранятся в `books.json` в формате:

```json
[
  {
    "author": "Автор",
    "title": "Название",
    "rating": 5,
    "date_read": "2026-05-19"
  }
]
```
