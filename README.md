# Трекер прочитанных книг

Консольное приложение на Python для отслеживания прочитанных книг.

## Как запустить

```bash
python main.py
```

## Меню

1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход

## Пример работы

Добавить книгу

Показать все книги
...

Данные хранятся в `books.json` в формате:
```json
